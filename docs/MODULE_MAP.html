Where each module lacks

Ordered by cost-to-close, not by severity. The first three are days of work, not weeks.

AC-8 · The trend is drawn but never tested M1 M7

A CI band is computed per run, but nothing compares two of them. PRD §11.6 requires change-detected / no-change by CI overlap on two runs, and a Theil–Sen slope with a bootstrap CI on four or more. grep -ri theil returns nothing in either tree. This is the project's central claim — never assert a trend without its CI — and the UI currently does exactly that. One pure function in M1 fixes the maths; M7 only renders it.

AC-10 · Distribution is an empty package M5

app/distribution/ is a 0-byte __init__.py. No Dev.to integration, no human approval gate, no publish audit log, no manual-export fallback. A full acceptance criterion with zero code.

AC-12 · The detector is never validated M1 M7

No labelling workflow, no precision/recall, no Cohen's kappa. The README says detection is "reproducible and independently testable" — but deterministic is not the same as accurate. PRD §11.7 asks for two independent annotators on ~10–15% of observations. This is the criterion most likely to be graded on, because it is what proves the technical claim.

Two of five gap types are dead code in production M3

SOURCE and REPRESENTATION are fully implemented and tested in M1 — and can never fire, because collection/sources/ is empty and nothing ever supplies prompted_observations to the gap detector. The README advertises all five types. Right now the running system does three.

AC-11 · The quota interface is stubbed everywhere M3

All five adapters return QuotaState(remaining_today=None, daily_limit=None, exhausted=False). Quota exhaustion detection now works on daily-limit 429s — good — but quota reporting and the per-provider cost view have no data source.

Four empty packages, five unused dependencies M2 M4

core/, db/, models/, orchestration/ and normalization/ are all 0 bytes, while sqlalchemy, alembic, celery, redis and psycopg ship in the image and are imported nowhere. Scaffolding abandoned mid-thought — and reviewers read it as such.

Suggested build order

Strictly dependency-ordered. Steps 1–3 are independent of each other and can run in parallel across the team; everything after step 3 needs step 1 landed.

Trend statistics

analysis/trend.py — CI-overlap verdict for 2 runs, Theil–Sen + bootstrap CI for 4+. Pure, ~150 LOC, testable in the same style as the scorer. Closes AC-8.
